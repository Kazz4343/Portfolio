## 🎯 Architecture & Performance Focus (Why Hire Me?)

As an engineer, I care deeply about user experience and technical efficiency. This portfolio was built with the following core principles in mind:

*   **⚡ Performance First:** Optimized images, lazy-loaded components, and code-splitting to ensure a near 100/100 Google Lighthouse performance score.
*   **📱 Semantic & Accessible:** Built using strict HTML5 semantic tags and ARIA attributes ensuring WCAG compliance for accessibility.
*   **🎨 Fluid UI/UX:** Responsive layouts engineered with a Mobile-First design philosophy, adapting beautifully from a 4-inch phone to a ultra-wide monitor.
*   **🧹 Clean Code & Typings:** Written using strict TypeScript types and modular component architecture for high maintainability.
